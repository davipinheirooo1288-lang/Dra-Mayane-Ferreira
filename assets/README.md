# Assets do site

Estas imagens são carregadas diretamente pelas seções do site. Mantenha os nomes abaixo para evitar quebrar o HTML:

- `template-hero.webp`
- `section-urgencia.webp`
- `section-sobre.webp`
- `section-institucional.webp`
- `section-areas.webp`
- `section-atendimento.webp`
- `template-processo.webp`
- `section-localidade.webp`
- `section-faq.webp`
- `og-mayane.jpg`
- `favicon.svg`

Recomendações para troca:

- Exportar em WebP.
- Manter proporção `1672x941` nas seções principais.
- Evitar compressão agressiva que borre textos do template.
- Depois de trocar uma imagem, rodar `npm run build` e testar desktop/mobile.

Os PNGs originais de referência ficam em `docs/template-original/` e não são enviados para a Vercel por causa de `.vercelignore`.
